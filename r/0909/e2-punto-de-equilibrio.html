Mapa rápido #

  • El punto de equilibrio (PE) es el volumen (en libros) o la facturación (en $ de INT) donde ingreso neto total = costo total que se le asigna: rentabilidad cero.
  • Hay dos modelos: costeo directo (el título paga sus costos directos; el CE se paga con el MCU) y costeo por absorción (el título paga todo: CDT + CE).
  • Seis fórmulas base, siempre sobre el INU/MCU, nunca sobre el PVP: CE/MCU, (CE+G)/MCU, CDT/INU, (CDT+G)/INU, (CE+CDT)/INU, (CE+CDT+G)/INU. El resultado sale en libros; para pasarlo a pesos de INT se multiplica por el INU (o se divide el numerador por el MCU%).
  • Varios títulos: promedios simples (tiradas iguales) o promedios ponderados por tirada (tiradas distintas): INUpp, MCUpp, MCU%pp, CDUpp.
  • Fuera del PE (ventas ≠ PE): por encima del PE cada libro extra da MCU (si el PE paga el CE) o INU (PE de la edición/absorción); lo impreso y no vendido es pérdida al CPU, no al CDU.
  • Toma de decisiones (T08): cada título se compara con los promedios MCTp y MCT%p y sale una de cuatro decisiones (no cambiar / mejorar MCU / mejorar marketing / discontinuar).

Clase T03: El punto de equilibrio, 1.ª parte #

Ideas centrales #

  • Cada libro debe pagar su CDT con el INT de sus ventas. El problema es cómo se paga la estructura: de ahí salen los dos modelos de costeo.
  • El PE es una herramienta de corto plazo para ver el umbral de rentabilidad de una empresa, un proyecto o un producto: indica el volumen físico y/o el monto de facturación que iguala el CGT (CDT + CE) con el INT. Rentabilidad cero.
  • La lógica: del INU de cada libro, una parte paga su propio costo directo (CDU) y lo que queda, el MCU, "paga" el CE. El PE es la cantidad de libros cuyo MCT acumulado iguala el CE. Antes del PE, cada libro achica el faltante del CE; después del PE, cada libro adicional es ingreso extra.
  • Si el PE es excesivo (el mercado no lo absorbe): subir el PVP, bajar el CDU o bajar el CE. Si baja el CDU sube el MCU y baja el PE; si baja el CE hacen falta menos libros. El límite del PVP lo pone el mercado (competencia y demanda). Si PE y PVP resultan ambos altos, quizás no conviene editar, salvo decisión política de la editorial (título "subsidiado" por otros rentables).

Conceptos clave #

  • Costeo por absorción: todos los costos se asignan a los títulos, sin distinguir directos de estructura.
  • Costeo directo: se valúan los libros con costos directos totales y se separa el CE, porque se supone que los libros no son culpables de los costos estructurales y no deben sufrir una asignación arbitraria. El precio queda "separado" del CE; después hay que ver cómo recuperarlo.
  • PE para pagar el CE (costeo directo): cantidad de ejemplares donde MCT = CE. Equivale a CGT = INT, porque INT = CDT + MCT y CGT = CDT + CE.
  • Dos formas de la fórmula (T03, pág. 3-4):
  • En libros: PE = CE / MCU.
  • En pesos (INT en el PE): PE = CE / MCU%.
  • Variables y unidades: CE en $; MCU en $ por libro; MCU% adimensional (fracción del INU); resultado en libros o en $ de INT.

Distinciones #

Costeo directo Costeo por absorción
Qué asigna al título Solo costos directos (CDU) Todo: CDU + CE
El CE Se separa y se paga con el MCU Se suma al CDT y se paga con el INU
Fórmula del PE (libros) CE / MCU (CE + CDT) / INU
Ingreso extra sobre el PE MCU × (Q − PE) INU × (Q − PE)

Ejemplos de la clase #

Ejemplo 1 (T03, pág. 4-5). PVP $14.000, dto 50 %, CDU $4.000, CE $240.000. INU = 14.000 × 0,5 = $7.000; MCU = 7.000 − 4.000 = $3.000; PE = 240.000 / 3.000 = 80 libros; INT = 80 × 7.000 = $560.000. MCU% = 3.000/7.000 = 0,4286; 240.000 / 0,4286 ≈ $559.960 (diferencia por redondeo del MCU%; exacto: $560.000). Por cada libro vendido por encima de 80, entran $3.000 extra. En 100 ejemplares: entran $700.000, CGT = 240.000 + 100 × 4.000 = $640.000, diferencia $60.000 = 3.000 × 20. ⚠ La clase escribe "$300 x 20 = $60.000": es $3.000 × 20.

Ejemplo 2 (T03, pág. 6-8). PVP $10.500, dto 30 %, CPU $3.000, gastos comerciales 35 % del CPU, CE $1.980.000. INU = $7.350; CDU = 3.000 + 1.050 = $4.050; MCU = $3.300; PE = 600 libros; INT en el PE = 600 × 7.350 = $4.410.000; MCU% = 0,4490 → 1.980.000/0,4490 ≈ $4.409.800 (redondeo). Distribución del INT en el PE: CE $1.980.000 + CDT $2.430.000 (4.050 × 600) = $4.410.000.

Qué pasa fuera del PE (tirada 1.000, ejemplo 2) #

Regla general (se usa en todos los problemas): - Se vende la tirada completa: ingreso extra = MCU × (tirada − PE) = 3.300 × 400 = $1.320.000. Chequeo: entran 7.350 × 1.000 = 7.350.000; salen 1.980.000 + 4.050.000 = 6.030.000; diferencia 1.320.000. - Se vende una cantidad intermedia (PE < Q < tirada): ingreso extra por lo vendido sobre el PE menos pérdida por lo impreso y no vendido, valuada al CPU (esos libros no se comercializaron, entonces no tienen gastos comerciales). - Q = 700: 3.300 × 100 − 3.000 × 300 = 330.000 − 900.000 = −$570.000. - Q = 800: 3.300 × 200 − 3.000 × 200 = 660.000 − 600.000 = +$60.000. - Se vende menos que el PE (Q = 400): faltante para el CE = MCU × (PE − Q) = 3.300 × 200 = $660.000, y pérdida por no vendidos = CPU × (tirada − Q) = 3.000 × 600 = $1.800.000. La clase los presenta como dos montos separados. - Si el mercado demanda menos que el PE: no publicar, financiarlo con otra publicación, pedir un crédito, etc. Si demanda más, se produce y el excedente genera ingreso extra.

Gráfica del PE (descripción en palabras) #

Dos ejes: horizontal = ejemplares vendidos; vertical = valores en $. Hay cuatro rectas: 1. CDT: arranca en 0 y sube $4.000 por unidad (pendiente = CDU). 2. CE: horizontal (constante) a la altura de $240.000. 3. CGT = CE + CDT: paralela a la del CDT, pero arranca en $240.000. 4. INT: arranca en 0 y sube $7.000 por unidad (pendiente = INU).

Como INU > CDU, la recta de INT tiene más pendiente que CDT y CGT, y por eso corta a la de CGT. Ese cruce es el PE (80 libros, $560.000; esos $560.000 de CGT son $240.000 de CE + $320.000 de CDT). A la izquierda del cruce INT < CGT: pérdida. A la derecha INT > CGT: ganancia, y la brecha vertical crece MCU por cada libro. Con ganancia deseada, la recta de costos que se cruza con INT arranca más arriba (CE + G) y el cruce se corre a la derecha (ejemplo: 630 libros en lugar de 600).

Clase T04: PE 2.ª parte (otros usos y ganancia) y 3.ª parte (varios títulos) #

Ideas centrales #

  • Además de pagar el CE, el PE sirve para: pagar solo la edición (CDT), pagar todo (CGT, absorción) y, en cualquier caso, agregar una ganancia deseada (G).
  • Cuando el CE ya está cubierto con otros títulos, interesa solo el PE de la edición: INT = CDT. El ingreso adicional se calcula con el INU (no con el MCU), porque ya no hay estructura que pagar: todo el INU de un libro más allá del PE es extra.

Conceptos clave: las seis variantes (resumen de la cátedra, T04 pág. 6-7) #

Variante Modelo En libros En pesos (INT en el PE)
a) Pagar el CE Directo CE / MCU CE / MCU%
b) Pagar el CE + ganancia Directo (CE + G) / MCU (CE + G) / MCU%
c) Pagar los costos directos (edición) Directo CDT / INU CDT
d) Pagar costos directos + ganancia Directo (CDT + G) / INU CDT + G
e) Pagar costos globales Absorción (CE + CDT) / INU = CGT / INU CGT
f) Pagar costos globales + ganancia Absorción (CE + CDT + G) / INU CGT + G

Las columnas de pesos de c) a f) son [reconstruido]: la cátedra da la fórmula en libros; el INT en el PE es PE × INU, que da esos montos. Variables: CE, CDT, G en $ (CDT = CDU × tirada); MCU e INU en $/libro; MCU% adimensional. Cómo leer la tabla: dividís por lo que aporta cada libro (MCU si lo que pagás es solo el CE; INU si lo que pagás incluye el CDT, porque en ese caso se está pagando el costo directo con el ingreso neto).

Distinciones #

Concepto Divisor Por qué
PE para el CE MCU Cada libro cubre su CDU y aporta el MCU a la estructura
PE de la edición INU El INT paga el CDT; el CE no entra
PE de la editorial (absorción) INU El INT paga CDT + CE
Ingreso adicional si el PE paga el CE MCU × (Q − PE) Antes del PE el MCU se iba al CE
Ingreso adicional si el PE es de edición o absorción INU × (Q − PE) Pasado el PE, el INU entero es extra

Ejemplos de la clase #

Ejercicio 1 (PE de la edición). Tirada 2.400, CDU $300, dto 40 %, PVP $1.500. INU = 900; CDT = 300 × 2.400 = $720.000. PE = 720.000/900 = 800 libros. Excedente = 1.600 libros; ingreso extra = 900 × 1.600 = $1.440.000. Distribución del INT total ($2.160.000 = 900 × 2.400): CDT $720.000 + ingreso extra $1.440.000.

Ejercicio 2 (absorción). Con lo anterior y CE $180.000: PE = (720.000 + 180.000)/900 = 1.000 libros; excedente 1.400; ingreso extra = 900 × 1.400 = $1.260.000.

Costeo directo con ganancia (T04, pág. 3-4). Ejemplo 2 de T03 con ganancia $99.000: PE = (1.980.000 + 99.000)/3.300 = 630 libros. En pesos: 2.079.000/0,4490 ≈ $4.630.290; verificación 630 × 7.350 = $4.630.500 (diferencia: redondeo del MCU%). Sin ganancia el PE era 600. Distribución del INT en el PE (se imprimen solo 630): CE $1.980.000 + ganancia $99.000 + CDT $2.551.500 (4.050 × 630) = $4.630.500. Si se vende la tirada completa (1.000): ingreso adicional sobre lo esperado = 3.300 × 370 = $1.221.000; entran 7.350.000 y salen 1.980.000 + 99.000 + 4.050.000 = 6.129.000.

Ejercicio integrador (PVP $2.000, dto 40 %, CPU $400, gastos comerciales 20 % del CPU, CE $600.000, tirada 1.500, ganancia $120.000): INU = 1.200; CDU = 400 + 80 = 480; MCU = 720; MCU% = 0,6. - A) Costeo directo, CE + ganancia: PE = 720.000/720 = 1.000 libros; en pesos 720.000/0,6 = $1.200.000. - Distribución en el PE: CE 600.000 + ganancia 120.000 + CDT 480.000 (480 × 1.000) = 1.200.000. - Vende la tirada (1.500): ingreso adicional = 720 × 500 = $360.000. - Vende 1.200: adicional = 720 × 200 = 144.000; no vendidos 300 × CPU 400 = 120.000 de pérdida; balance +$24.000. - Vende 800: faltante para el CE = 720 × 200 = $144.000; pérdida = 400 × 700 = $280.000 (700 no vendidos). - B) PE de la edición + ganancia: (480 × 1.500 + 120.000)/1.200 = 840.000/1.200 = 700 libros. Vendiendo la tirada: INU × (1.500 − 700) = 1.200 × 800 = $960.000 (puede ir a la estructura o ser ganancia adicional). - C) Absorción + ganancia: (600.000 + 720.000 + 120.000)/1.200 = 1.200 libros.

PE para varios títulos (T04, 3.ª parte) #

A) Tiradas iguales. Se trabaja con promedios simples de los valores unitarios (INUp, CDUp, MCUp = Σ/n); después MCU%p = MCUp / INUp y CDT = CDUp × PE. Es como editar un único título "promedio". Ejemplo de la clase (6 títulos A-F; INU 3.000 / 4.500 / 6.000 / 4.800 / 7.200 / 3.600; CDU 1.500 / 2.000 / 2.000 / 2.000 / 3.000 / 1.500; CE $3.000.000; ganancia $1.000.000): - MCU: 1.500 / 2.500 / 4.000 / 2.800 / 4.200 / 2.100; Σ = 17.100. MCUp = 2.850; INUp = 29.100/6 = 4.850; MCU%p = 0,5876; CDUp = 12.000/6 = 2.000. - PE (libros) = 4.000.000 / 2.850 = 1.403,5 libros. Mismo ejemplo con Q = 500 / 1.200 / 800 / 1.500 / 2.000 / 600 (ΣQ = 6.600): - ING = 35.460.000; MCG = 20.810.000; CDG = 14.650.000. ⚠ La tabla de la clase tiene dos erratas: MCT de A es 750.000 (no 7.500.000) y CDT de F es 900.000 (no 9.000.000); los totales sí son correctos. - INUpp = 35.460.000/6.600 = $5.372,7; MCUpp = 20.810.000/6.600 = $3.153; MCU%pp = 3.153/5.372 = 0,5869. - a) PE directo, CE + ganancia = 4.000.000/3.153 = 1.268,6 libros (la clase: 1.268,63). - b) PE de la edición = CDG/INUpp = 14.650.000/5.372,7 = 2.726,7 libros (la clase da 2.727,10 por redondear el INUpp a 5.372). - c) PE absorción + ganancia = (3.000.000 + 14.650.000 + 1.000.000)/5.372,7 = 3.471,2 libros (la clase: 3.471,70, mismo motivo). - Las pequeñas diferencias de decimales vienen del redondeo del INUpp: usá la cifra de la clase como referencia.

Clase T08: Toma de decisiones y PE para varios títulos #

Ideas centrales #

  • Se combinan dos análisis: PE global (con promedios ponderados) y decisión por título (con promedios de los márgenes totales).
  • Para el PE: MCUpp = MCG / ΣQ y MCU%pp = MCUpp / INUpp.
  • Para decidir: MCTp = MCG / n.º de títulos y MCT%p = MCG / ING. Nota de la cátedra: MCU%pp y MCT%p son iguales (ambos dan MCG/ING).

Conceptos clave: cuadro de decisión #

Cada título se ubica según dos preguntas: ¿su MCT supera al MCTp? ¿su MCT% supera al MCT%p?

MCT vs MCTp MCT% vs MCT%p Cuadrante Decisión
Arriba Arriba A-B No realizar ningún cambio (bien posicionado)
Arriba Abajo A-D Mejorar el MCU (aporta mucho en pesos, pero con margen % bajo: subir PVP o bajar costos)
Abajo Arriba C-B Mejorar las estrategias de marketing (buen margen %, pero vende poco: impulsar ventas)
Abajo Abajo C-D Discontinuar

Convención de la cátedra: A = MCT arriba del promedio, C = abajo; B = MCT% arriba, D = abajo.

Ejemplos de la clase #

Ejercicio 1 (5 títulos, dto 40 %). Absorción: método unitario y problema del reparto (Maradei, pág. 45-46) #

  • En absorción cada título debe absorber la parte del CE que le corresponde; con un solo título es directo, con varios es difícil de repartir (ejemplo del libro: el aumento de la luz, o repartir un flete por los m² que ocupa cada libro en la camioneta).
  • Método unitario (el más usado en editoriales): cuando la estructura sirve a un único título, CGT / tirada = cuánto debe recuperar cada libro. Ej.: 1.000 ejemplares y CGT $400.000 → $400 por libro [cuenta del libro], lo que puede dejar el PVP por encima del precio de mercado.
  • Es poco aconsejable cuando se pueden separar fijos de directos: trabaja con estimaciones generales y puede "descolocar" al libro del precio de mercado. Por eso se propone el costeo directo: el precio queda separado del CE y después se ve cómo recuperarlo (pág. 46-47).
  • Con el PE se hace análisis de sensibilidad: modificar precio, ventas, costos (fijos y variables), MCU o descuentos y ver el nuevo resultado (Maradei, pág. 47).

Fórmulas de PE para VARIOS títulos con tiradas distintas (para el simulador) #

Variables: por título i, INU_i, CDU_i, Q_i (tirada) y MCU_i = INU_i − CDU_i. Globales: ING = Σ INU_i·Q_i; CDG = Σ CDU_i·Q_i; MCG = Σ MCU_i·Q_i = ING − CDG; ΣQ = Σ Q_i. Promedios ponderados: INUpp = ING/ΣQ; MCUpp = MCG/ΣQ; MCU%pp = MCUpp/INUpp = MCG/ING; CDUpp = CDG/ΣQ.

Cálculos: procedimiento paso a paso #

  1. Armar el escandallo: PVP → INU (dto comercial) → CPU → gastos comerciales (cada uno sobre su base) → CDU → MCU y MCU%.
  2. Identificar qué paga el PE: ¿solo el CE?, ¿la edición?, ¿todo? ¿Con o sin ganancia? Elegí la fórmula de la tabla.
  3. Si hay varios títulos: tiradas iguales → promedios simples; tiradas distintas → ponderados por Q (ΣQ en el divisor).
  4. Calcular el PE en libros (y en pesos si lo piden: PE × INU, o numerador / MCU%).
  5. Armar la distribución del INT (CE + ganancia + CDT del PE) y analizar qué pasa fuera del PE con tirada y ventas.
  6. Si piden decisión: MCTp y MCT%p → cuadrante.

Lo imprescindible (repaso de 5 minutos) #

  • PE = punto donde INT = costo asignado; rentabilidad cero.
  • El MCU paga el CE: PE directo = CE / MCU (libros) o CE / MCU% (pesos de INT).
  • Con ganancia, el numerador es CE + G (o CDT + G, o CE + CDT + G).
  • PE de la edición = CDT / INU; PE por absorción = (CE + CDT) / INU (más G si hay).
  • Costeo directo: el libro no es "culpable" del CE; absorción: todo se asigna al título.
  • Ingreso adicional: MCU × (Q − PE) si el PE paga el CE; INU × (Q − PE) si paga edición/absorción.
  • Ventas entre el PE y la tirada: ingreso extra menos pérdida de no vendidos (CPU × no vendidos).
  • Ventas por debajo del PE: faltante del CE = MCU × (PE − Q) y pérdida = CPU × (tirada − Q).
  • Varios títulos con tiradas iguales: promedios simples; con tiradas distintas: ponderados (÷ ΣQ).
  • MCUpp = MCG/ΣQ; MCU%pp = MCUpp/INUpp = MCG/ING; MCTp = MCG/n; MCT%p = MCG/ING (MCU%pp = MCT%p).
  • Decisión: arriba/arriba no cambiar; MCT arriba y % abajo mejorar MCU; MCT abajo y % arriba mejorar marketing; abajo/abajo discontinuar.
  • Gráfica: 4 rectas (CDT, CE, CGT, INT); INT corta a CGT en el PE; tiene más pendiente porque INU > CDU.
  • PE excesivo → subir PVP, bajar CDU o CE; o no editar (salvo título subsidiado por decisión política).
  • MCU% menor que 25-30 % suele indicar que no conviene publicar.
  • Resultado en pesos para un volumen de ventas: MCU% × INT − CE; volumen para una ganancia: (CE + G) / MCU% en pesos (Maradei, pág. 67-68).
  • Varios títulos con tiradas distintas: PE = (CE + G) × ΣQ / MCG (directo); edición = CDG × ΣQ / ING; absorción = (CE + CDG + G) × ΣQ / ING. Supone vender en la proporción de las tiradas.
  • Absorción con varios títulos: el CE es difícil de repartir (método unitario: CGT/tirada); por eso se prefiere el costeo directo.
  • Resultado = MCU × Q − CE: cada libro por encima del PE suma exactamente el MCU.

Autoevaluación

20 preguntas. Tocá «Ver respuesta» para comprobar. En Galera podés responder con puntaje.

  1. En el costeo directo, el punto de equilibrio en libros para pagar el costo de estructura se calcula como:

    • a) CE / CDU
    • b) CE / INU
    • c) CE / MCU
    • d) CDT / MCU
    Ver respuesta

    c) el MCU es lo que cada libro aporta al CE; PE = CE / MCU.

  2. En el costeo por absorción, el PE en libros para pagar los costos globales se obtiene dividiendo (CE + CDT) por el INU.

    Verdadero o falso.

    Ver respuesta

    Verdadero. en absorción el INU debe pagar CDT y CE: PE = (CE + CDT) / INU.

  3. Si se agrega una ganancia deseada G al PE en costeo directo para pagar el CE, la fórmula en libros es:

    • a) (CE + G) / MCU
    • b) CE / MCU − G
    • c) CE / (MCU + G)
    • d) (CE + G) / INU
    Ver respuesta

    a) la ganancia se suma al numerador: (CE + G) / MCU.

  4. Cuando el mercado absorbe más libros que el PE, el ingreso adicional en costeo directo es igual al INU por el excedente de libros.

    Verdadero o falso.

    Ver respuesta

    Falso. en costeo directo el ingreso adicional es MCU × excedente; el INU se usa en el PE de la edición o de absorción.

  5. El PE de la edición (costos directos) indica:

    • a) los libros que hay que vender para cubrir el CGT con ganancia
    • b) los libros que hay que vender para que INT = CDT, sin considerar el CE
    • c) los libros que hay que vender para que INU = CE
    • d) los libros que hay que vender para que MCT = CE
    Ver respuesta

    b) INT = CDT, sin considerar el CE; PE = CDT / INU.

  6. Se imprimen 1.000 libros, el PE es 600, el MCU es $3.300 y el CPU $3.000; se venden 700. El resultado es:

    • a) +$330.000
    • b) +$570.000
    • c) −$900.000
    • d) −$570.000
    Ver respuesta

    d) 3.300 × 100 − 3.000 × 300 = 330.000 − 900.000 = −570.000.

  7. Los libros impresos y no vendidos se valúan al CDU porque tuvieron gastos comerciales.

    Verdadero o falso.

    Ver respuesta

    Falso. no se comercializaron, no tienen gastos comerciales: se valúan al CPU.

  8. El PE en pesos con el costeo directo del CE se calcula como:

    • a) CE / PVP
    • b) CE / MCU%
    • c) MCU / CE
    • d) CE × MCU%
    Ver respuesta

    b) PE ($ de INT) = CE / MCU%.

  9. Para varios títulos con tiradas distintas se deben usar:

    • a) el promedio de los MCU%
    • b) el valor del título con más tirada
    • c) promedios simples de INU y CDU
    • d) promedios ponderados por tirada (dividir por la suma de tiradas)
    Ver respuesta

    d) con tiradas distintas cada título pesa según su Q: promedios ponderados.

  10. En T08, el MCU%pp y el MCT%p son iguales (ambos MCG / ING).

    Verdadero o falso.

    Ver respuesta

    Verdadero. ambos son MCG / ING, según la nota de T08.

  11. Un título tiene MCT por debajo del MCTp y MCT% por encima del MCT%p. La decisión es:

    • a) discontinuarlo
    • b) no realizar ningún cambio
    • c) mejorar las estrategias de marketing
    • d) mejorar el MCU
    Ver respuesta

    c) MCT bajo y MCT% alto: buen margen % pero poco aporte total; hay que impulsar ventas.

  12. Si un título tiene MCT y MCT% por debajo de los promedios, conviene discontinuarlo.

    Verdadero o falso.

    Ver respuesta

    Verdadero. el cuadrante C-D (abajo en ambos) indica discontinuar.

  13. (Problema) PVP $1.000, dto 40 %, CPU $200, gastos comerciales 20 % del CPU, CE $150.000. ¿Cuántos libros y qué INT (en $) hacen falta para pagar el CE? ¿Y para pagar el CE más una ganancia de $30.000?

    Ver respuesta

    416,67 libros (≈ 417) y $250.000 de INT; con ganancia, 500 libros y $300.000 — INU = 600, CDU = 240, MCU = 360, MCU% = 0,6; 150.000/360 y 150.000/0,6; 180.000/360 y 180.000/0,6.

  14. (Problema) Con los datos de la pregunta 13 y una tirada de 1.000: calculá el PE por absorción (sin ganancia) y el PE de la edición con ganancia de $60.000.

    Ver respuesta

    Absorción 650 libros; edición con ganancia 500 libros — (150.000 + 240.000)/600 = 650; (240.000 + 60.000)/600 = 500.

  15. (Problema) Con CE $144.000 (resto de los datos de la 13), tirada 1.000 y 700 libros vendidos: ¿cuál es el resultado respecto del PE?

    Ver respuesta

    +$48.000 — PE = 144.000/360 = 400; ingreso extra 360 × 300 = 108.000; pérdida de 300 no vendidos × 200 = 60.000; 108.000 − 60.000.

  16. Un libro tiene PVP $35, dto 30 %, CPU $10, gastos comerciales 35 % del CPU y CE $66.000. El PE en libros (costeo directo del CE) es:

    • a) 6.000 libros
    • b) 2.700 libros
    • c) 4.489 libros
    • d) 8.800 libros
    Ver respuesta

    a) INU 24,5; CDU 13,5; MCU 11; PE = 66.000/11 = 6.000 (Maradei, pág. 56).

  17. Con varios títulos de tiradas distintas, el PE en libros para pagar CE + ganancia se calcula como:

    • a) (CE + G) dividido el MCTp
    • b) (CE + G) dividido el MCU% ponderado
    • c) (CE + G) × ΣQ dividido el MCG
    • d) (CE + G) dividido el promedio simple de los MCU
    Ver respuesta

    c) (CE + G)/MCUpp con MCUpp = MCG/ΣQ equivale a (CE + G) × ΣQ / MCG; el promedio simple solo vale con tiradas iguales.

  18. (Problema) PVP $50, dto 40 %, CPU $10, gastos comerciales 20 % del CPU, CE $15.000, tirada 1.500, ganancia $3.000. Calculá el PE en libros y en pesos (costeo directo, CE + G) y el resultado si se venden 1.200 libros.

    Ver respuesta

    1.000 libros, $30.000 y +$600 — INU 30; CDU 12; MCU 18; PE = 18.000/18 = 1.000; 18.000/0,6 = 30.000; a 1.200: 18 × 200 − 10 × 300 = 3.600 − 3.000 = +600.

  19. Una editorial tiene CDT = 60 % del INT y CE $50.000 (MCU% = 0,4). Con ventas (INT) de $180.000, la rentabilidad es:

    • a) $130.000
    • b) $55.000
    • c) $72.000
    • d) $22.000
    Ver respuesta

    d) PE = 50.000/0,4 = 125.000; ventas sobre el PE 55.000 × 0,4 = 22.000 (o 180.000 − 108.000 − 50.000).

  20. En el costeo por absorción con varios títulos, el CE se reparte con facilidad entre los títulos, porque cada uno sabe qué parte consume.

    Verdadero o falso.

    Ver respuesta

    Falso. es difícil determinar qué parte de luz, flete, etc. consume cada título; por eso se usa el costeo directo (Maradei, pág. 45-46).
